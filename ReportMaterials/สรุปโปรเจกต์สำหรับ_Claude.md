# สรุปโปรเจกต์ (ส่งต่อให้ Claude ในแชท)

## ภาพรวม
- เกมออกกำลังกายด้วย **แผ่นเหยียบ 4 ทิศ** (Exergame) ทำด้วย **Unity 2022.3** โฟลเดอร์ `E:\Unity\My project (5)`
- แผ่นเหยียบต่อเป็นจอย: บน = Joystick1Button5, ล่าง = Button11, ซ้าย = Button8, ขวา = Button3 (แผ่นไม่มีราวจับ จึงต้องออกแบบให้มีเวลาตอบสนองพอ)
- ทุกหน้าเมนูใช้ได้ทั้งแผ่นเหยียบ คีย์บอร์ด (WASD / ลูกศร) และเมาส์ เปลี่ยนปุ่มได้ในหน้า Option (`GameInputBindings.cs`)
- ลำดับหน้าจอ: Mainmenu → QuestBoard (เลือกเกม) → เกม 3 โหมด → หน้าสรุปผล (เล่นอีกครั้ง / กลับหน้าเลือกเกม)

## โหมดเกม
1. **ถ้ำกู้ระเบิด** (Tutorialmine, Cave1, Cave2, Cave3): เดินบนตารางแบบ Minesweeper
   - เปิดช่องแล้วบอกจำนวนกับดักรอบๆ ถ้าเป็น 0 จะเปิดช่องรอบๆ ต่อเองแบบ BFS
   - นับว่าเคลียร์เฉพาะปักธงถูกจุด และการฆ่ามอนสเตอร์
   - Cave3 มีมอนสเตอร์เดินไล่ผู้เล่น ผู้เล่นโจมตีอัตโนมัติ และระเบิดทำดาเมจมอนสเตอร์ได้
   - หน้าสรุปผลมีแถบสถิติการเคลื่อนไหว
2. **CookieRunner** (วิ่งไม่รู้จบ): บน = กระโดด, ล่าง = สไลด์
   - มีหัวใจ 3 ดวง เก็บไอเทมหัวใจฟื้นได้
   - ไอเทม: Shield 10 วินาที (กะพริบเตือนช่วง 3 วินาทีสุดท้าย), Blast วิ่งเร็ว, Giant ตัวใหญ่, Magnet
   - ติด Blast หรือ Giant แล้วชนสิ่งกีดขวาง สิ่งกีดขวางจะแตกเป็นชิ้น (`CookieSmashFx.cs`) หลัง Blast หมดจะอมตะกะพริบ 1.5 วินาที
   - Blast หมดเวลาตอนอยู่เหนือหลุม จะลอยต่อจนถึงพื้นก่อน
   - มี **8 ระดับ/โซน** ตามระยะทาง:

     | ระยะ (ม.) | โซน |
     |---|---|
     | 0 | Crystal Cavern |
     | 150 | Emerald Grotto |
     | 300 | Abandoned Mine |
     | 450 | Shadow Depths |
     | 650 | Frozen Grotto (ความเร็วสูงสุด) |
     | 850 | Fungal Forest (เห็ดยักษ์) |
     | 1050 | Amber Hollow (รากไม้ห้อย) |
     | 1250 | Molten Core (แท่งคริสตัลแหลม) |

   - ความเร็วสูงสุด 1.4 เท่า และจำปุ่มกระโดดล่วงหน้า 0.3 วินาที (jump buffer)
   - ฉากหลุมแบบสุ่มสร้าง (`CookieMapSpawner.cs`): หลุมกว้าง 2.5–3 ม., พื้นพักระหว่างหลุมอย่างน้อย 5.5 ม., ด่านหลังๆ หลุมโผล่บ่อยขึ้น
   - ก่อนประตูเปลี่ยนโซนเป็นพื้นเรียบ 25 ม. ไม่มีหลุมหรือสิ่งกีดขวาง
   - มอนสเตอร์หยุดเดินห่างสิ่งกีดขวางก่อนหน้าอย่างน้อย 8 ม.
   - เสียง: เพลง 0.45, เสียงเอฟเฟกต์ **0.07** (ผู้ใช้เลือกเอง)
3. **Arrow Memory** (จำลูกศร): พอร์ตมาจากเว็บเกม `pulse-steps`
   - ระดับความยาก ง่าย / ปกติ / ยาก มีหัวใจ 3 ดวง ผ่านทุก 3 รอบได้หัวใจ +1 และเวลา +30 วินาที
   - มีเสียงพูดบอกทิศ (บน/ล่าง/ซ้าย/ขวา) และปุ่มไอคอนเปิด/ปิดเสียงพูด
   - กดเริ่มแล้วนับถอยหลัง 3-2-1 ครั้งเดียวต่อเกม เสียง "เริ่ม" พูดครั้งเดียวตอนถึงตาผู้เล่นรอบแรก
   - ระดับยากเร่งเสียงพูดแค่ 1.1 เท่า และค้างลูกศรไว้จนพูดจบ

## หน้าเมนู
- **Mainmenu:** มีแถบบอกปุ่มด้านล่าง และเอฟเฟกต์เคลื่อนไหว (`MenuAmbientFx.cs`): ตะเกียงกะพริบ แสงอาทิตย์ เมฆ หิ่งห้อย ใบไม้ปลิว ภาพซูมช้าๆ
- **QuestBoard:** มีการ์ดเกม 3 ใบ (`QuestBoardDecor.cs`) และเอฟเฟกต์ในโรงเตี๊ยม: ประกายไฟจากเตาผิง ลำแสงจากหน้าต่าง เปลวเทียน

## การคำนวณแคลอรี่
- โหมดถ้ำและโหมดวิ่งใช้สูตร ACSM: (METs × 3.5 × น้ำหนัก กก.) / 200 × นาที
  - ถ้ำ: METs ค่าเริ่มต้น 4.0
  - วิ่ง: METs 5.0
- โหมดจำลูกศรประมาณจากจำนวนก้าว × KcalPerStep
- ตัวอย่าง: น้ำหนัก 60 กก. วิ่ง 5 นาที = 26.25 kcal
